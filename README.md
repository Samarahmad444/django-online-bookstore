Online Bookstore — Web-Based E-Commerce Application:
A Django-based e-commerce web application developed as an online bookstore. The application provides core e-commerce functionality, including user authentication, product browsing, shopping cart management, order processing, and inventory management.

Features:
User authentication
Book and product browsing
Shopping cart management
Order processing
Stock availability validation
Database-driven inventory management
Automatic inventory updates after purchases

Technologies:
Python
Django
SQLite
HTML
CSS
Bootstrap

How It Works:
The application allows users to browse available books, add products to their shopping cart, and place orders.
Inventory and order information is managed through the application's database. During the purchasing process, the system validates product availability and updates inventory quantities after successful purchases.

Project Purpose:
This project was developed to apply full-stack web development concepts using Django, including:
Backend web development
Database integration
User authentication
E-commerce workflows
Inventory and order management
Frontend development with HTML, CSS, and Bootstrap
